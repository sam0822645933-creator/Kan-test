# МебельОпт — сайт для продажи мебели оптом и в розницу

Готовый одностраничный сайт-визитка для мебельного бизнеса: каталог с фильтрами по категориям, условия для оптовых клиентов, форма заявки. Сайт простой — это обычные файлы HTML, CSS и JavaScript, без сложных программ и баз данных, поэтому его легко открыть и редактировать даже без опыта в программировании.

## Как посмотреть сайт

Просто откройте файл `index.html` двойным щелчком — он откроется в браузере (Chrome, Edge, Яндекс.Браузер и т.д.). Интернет для просмотра не нужен — все стили и иконки уже встроены в сайт.

## Структура файлов

```
index.html      — сама страница: весь текст и разметка сайта
css/style.css   — оформление (цвета, шрифты, расположение блоков)
js/main.js      — «оживляет» сайт: меню, фильтры каталога, товары, форма
```

Если нужно поменять текст (заголовки, описания, отзывы) — открывайте `index.html` в любом текстовом редакторе (например, Блокнот, VS Code, Notepad++) и меняйте текст между тегами. HTML-теги (слова в угловых скобках `< >`) трогать не обязательно, если вы не меняете разметку.

## Что стоит настроить под свою компанию

1. **Название и контакты.** В `index.html` замените:
   - `МебельОпт` — на название вашей компании (встречается в шапке, футере, `<title>`);
   - телефон `8 (800) 123-45-67` (несколько мест: шапка, блок «Контакты», футер);
   - почту `info@mebelopt.example`;
   - адрес `г. Москва, Мебельный проезд, д. 10`.

2. **Товары и цены.** Список товаров каталога находится не в `index.html`, а в файле `js/main.js`, в самом начале — массив `products`. Каждая строка — один товар:
   ```js
   { category: 'sofa', name: 'Диван "Комфорт" 3-местный', price: 34990, wholesalePrice: 29990, color: '#C68B59' },
   ```
   - `category` — категория (`sofa`, `bed`, `wardrobe`, `table`, `kitchen`, `office`, `kids`, `mattress`) — от неё зависит, в каком фильтре появится товар;
   - `name` — название;
   - `price` — розничная цена (за 1 шт.);
   - `wholesalePrice` — оптовая цена (от 10 шт.);
   - `color` — цвет фона карточки товара (можно оставить любой из готовых или задать свой HEX-код).

   Чтобы добавить товар — скопируйте одну строку и измените в ней данные. Чтобы убрать — удалите строку целиком.

3. **Условия опта.** Таблица скидок по объёму — в `index.html`, ищите раздел `<!-- ======= ОПТОВЫМ КЛИЕНТАМ ======= -->`.

4. **Цвета сайта.** В файле `css/style.css` в самом начале есть блок `:root { ... }` — там собраны все основные цвета сайта (например, `--color-accent` — акцентный оранжевый цвет). Поменяйте HEX-код — и цвет изменится по всему сайту.

## Важно про форму заявки

Сейчас при отправке формы «Оставить заявку» показывается сообщение об успехе, но **заявка никуда реально не отправляется** — ни на почту, ни в мессенджер. Это сделано специально, чтобы сайт можно было проверить сразу, без дополнительных настроек.

Чтобы заявки действительно приходили вам (например, на почту или в Telegram), есть два простых варианта без своего сервера:
- **Formspree** (formspree.io) — бесплатный сервис: регистрируетесь, получаете свой адрес формы и подставляете его в `index.html` в теге `<form id="orderForm" ...>` (добавляете `action="https://formspree.io/f/ВАШ_КОД"` и `method="POST"`), после чего можно убрать код показа сообщения об успехе в `js/main.js` — форма будет отправляться сама.
- **Готовый конструктор форм / чат-бот**, который умеет присылать заявки в Telegram или WhatsApp.

Если захотите — можете попросить помочь подключить один из этих вариантов.

## Как опубликовать сайт в интернете (бесплатно)

Проще всего — через **GitHub Pages**:
1. Загрузите папку с сайтом (этот репозиторий) на GitHub.
2. В настройках репозитория откройте раздел **Pages** и включите публикацию из ветки с сайтом (папка `/root`).
3. Через пару минут сайт будет доступен по ссылке вида `https://ваш-логин.github.io/название-репозитория/`.

Также подойдут бесплатные хостинги **Netlify** или **Vercel** — туда можно просто перетащить папку с файлами сайта через их сайт, без работы с кодом.
